INSTALL

安装步骤

三步完成安装，立即开始使用

1

下载插件源码

下载本插件的完整源码文件夹（包含 manifest.json、background.js、content.js 等文件），解压到本地任意目录。

2

打开扩展管理页面

在 Chrome / Edge 浏览器地址栏输入 chrome://extensions 并回车，打开扩展程序管理页面。

3

开启开发者模式

点击页面右上角「开发者模式」开关，将其切换为开启状态（蓝色），页面会出现「加载已解压的扩展程序」按钮。

4

加载已解压扩展

点击「加载已解压的扩展程序」，选择刚才解压的插件源码文件夹，确认后插件即出现在扩展列表中，安装完成。

提示：本插件通过「加载已解压扩展程序」方式安装，无需上架应用商店。安装后请刷新目标商品详情页，页面右侧将出现「获取图片」悬浮按钮。
USAGE

使用方法

三步完成商品图片提取与下载

打开商品详情页

在淘宝、京东或拼多多打开任意商品详情页，等待页面完全加载。

点击获取图片

点击页面右侧的「获取图片」悬浮按钮，插件将自动扫描并提取所有商品图片。

选择并下载

在画廊页勾选需要的图片，点击「下载选中」即可批量保存为 PNG 到本地。
